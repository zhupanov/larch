# Rebase checkpoint routing

**Consumer**: `/implement` orchestrator.
**Contract**: `CHECKPOINT_NEXT=continue|load-routing` macro directives plus stdout-KV detail for `scripts/larch.sh push checkpoint-probe`, the Step 3 `checks-commit-route` 4.r relay, the Step 6 `checks-commit-route` 7.r relay, and the Step 7a wrapper relay.
**When to load**: for absorbed checkpoint `1.r`, **MANDATORY: READ ENTIRE FILE** only when `BOOTSTRAP_NEXT=rebase-routing` from the Step 0 bootstrap stdout envelope selects the rebase-routing path. For folded checkpoints `4.r`, `7.r`, and `7a.r`, load only when the macro directive is `CHECKPOINT_NEXT=load-routing`, or when `CHECKPOINT_NEXT` is missing or malformed. The absorbed `1.r` degraded-tools carve-out comes first: when `DEGRADED_PROMPT_REQUIRED=true`, **MANDATORY: READ ENTIRE FILE** `${CLAUDE_PLUGIN_ROOT}/skills/implement/references/bootstrap-recovery.md` for degraded-prompt handling before treating absent routing keys as rebase failure.

**Absorbed Step 1.r.** For checkpoint `1.r`, the orchestrator receives the rebase result from the Step 0 bootstrap envelope (`ROUTE=`, `REBASE_RC=`, and related keys), not a standalone probe process. Entry is selected by `BOOTSTRAP_NEXT=rebase-routing` from the Step 0 envelope; reserve `CHECKPOINT_NEXT=continue|load-routing` for folded checkpoints `4.r`/`7.r`/`7a.r`. Load this reference for Step 1.r only when that bootstrap directive is present. Do **not** use missing or malformed `CHECKPOINT_NEXT` as the absorbed `1.r` entry predicate. When `DEGRADED_PROMPT_REQUIRED=true`, **MANDATORY: READ ENTIRE FILE** `${CLAUDE_PLUGIN_ROOT}/skills/implement/references/bootstrap-recovery.md` for degraded-prompt handling before treating absent routing keys as rebase failure. `4.r`, `7.r`, and `7a.r` relay probe output from composites or wrappers.

`scripts/larch.sh push checkpoint-probe` accepts `--forked-target true|false`; `true` defaults the base to `upstream/main` unless `--base-remote` or `--base-ref` is supplied explicitly.

Before emitting this contract, the probe regenerates and continues a conflict
set confined to `config.REBASE_AUTORESOLVE_GENERATED_FILES`. This applies to
every checkpoint caller, including 4.r, 7.r, and 7a.r. Mixed or regeneration-
failed conflicts remain in progress and use the existing conflict route below.

**Orchestrator contract: absorbed `1.r` (Step 0 envelope only)** (token-aware KV scan; multiple `KEY=value` tokens per line allowed: mirror Step 5-style parsing):

1. Do **not** invoke `scripts/larch.sh push checkpoint-probe` prompt-side for `1.r`. Do **not** branch on `step-0-bootstrap.sh` wrapper process exit code: bootstrap returns exit `0` while relaying the internal probe rc in `REBASE_RC=`.
2. This section is reached only after `BOOTSTRAP_NEXT=rebase-routing` from the Step 0 envelope. Branch on envelope `ROUTE=` (`continue` | `conflict` | `bail`) and `REBASE_RC=` (internal probe subprocess return code) **and** `REBASE_OUTCOME=` / `REBASE_ERROR=` / `CONFLICT_FILES=` from the Step 0 stdout envelope:
   - **`ROUTE=conflict`** (typically `REBASE_RC=1`, `REBASE_OUTCOME=conflict`): print `🔃 1.r: plan materialization | rebase: conflict detected, invoking Conflict Resolution Procedure (caller_kind=early_rebase)`. Parse `CONFLICT_FILES=<comma-separated list>` from the envelope; if the line is missing: defensive only: fall back to `git diff --name-only --diff-filter=U`. **MANDATORY: READ ENTIRE FILE** before executing the Conflict Resolution Procedure: `${CLAUDE_PLUGIN_ROOT}/skills/implement/references/conflict-resolution.md`. Invoke the Conflict Resolution Procedure with `caller_kind=early_rebase` and the parsed `CONFLICT_FILES` (spawn `larch:ci-fixer` `MODE=conflict`; do not Read conflicted hunks in the main agent). On success, continue. On hard failure, the procedure runs `"${CLAUDE_PLUGIN_ROOT}/scripts/larch.sh" git rebase-abort`, sets `STALL_TRACKING=true`, and skips to Step 18.
   - **`ROUTE=bail`** (`REBASE_OUTCOME=failed`): read `REBASE_ERROR=...` from the envelope. If the value begins with `unexpected-rc-`, print `**⚠ Rebase onto main failed unexpectedly (exit $rc). Bailing to cleanup.**` (derive the numeric exit token from the suffix after `unexpected-rc-` when present; otherwise use `REBASE_RC`), set `STALL_TRACKING=true`, and skip to Step 18. **Otherwise** print `**⚠ Rebase onto main failed (non-conflict): $REBASE_ERROR. Bailing to cleanup.**`, set `STALL_TRACKING=true`, and skip to Step 18.
   - **Other non-zero `REBASE_RC` with malformed `ROUTE`**: treat as bail: print `**⚠ Rebase onto main failed unexpectedly (exit $rc). Bailing to cleanup.**`, set `STALL_TRACKING=true`, and skip to Step 18.
   - **`ROUTE=continue`** (`REBASE_RC=0`, `REBASE_OUTCOME=ok` or `skipped`): this is defensive after a fail-closed macro load. On the envelope, check `SKIPPED_ALREADY_PUSHED=true` **before** `SKIPPED_ALREADY_FRESH=true`. If either skip marker is present, silently continue to Step 2; otherwise continue to Step 2. Phantom tail KVs (`PHANTOM_*`) may trail on the same stream: treat them as advisory.

**Orchestrator contract: folded and direct probe relays (`4.r`, `7.r`, `7a.r`)** (token-aware KV scan; multiple `KEY=value` tokens per line allowed: mirror Step 5-style parsing):

1. This section is reached only after `CHECKPOINT_NEXT=load-routing` or equivalent fail-closed load. The captured stdout is the contract stream. For `4.r`, the call is the Step 3 `checks-commit-route` composite, which invokes the probe internally and re-emits the probe stdout, including `CHECKPOINT_NEXT`, before its terminal `NEXT_ACTION=continue`. For `7.r`, the call is the Step 6 `checks-commit-route` composite, which invokes the probe internally and re-emits the probe stdout, including `CHECKPOINT_NEXT`, before its terminal `NEXT_ACTION=continue`. For `7a.r`, the call is `implement step-7a`, which invokes the probe internally and re-emits the probe stdout, including `CHECKPOINT_NEXT`, before its final KV tail.
2. Branch inside this reference on the process exit code **and** `REBASE_OUTCOME=` / `REBASE_ERROR=` / `CONFLICT_FILES=` keys emitted on stdout:
   - **Exit 1 (`REBASE_OUTCOME=conflict`)**: print `🔃 <step-prefix>: <short-name> | rebase: conflict detected, invoking Conflict Resolution Procedure (caller_kind=early_rebase)`. Parse `CONFLICT_FILES=<comma-separated list>` from the captured stdout; `--keep-on-conflict` leaves the rebase in progress so this list is authoritative for Phase 1. (If the line is missing: defensive only: fall back to `git diff --name-only --diff-filter=U` to enumerate the in-progress rebase's unmerged paths.) **MANDATORY: READ ENTIRE FILE** before executing the Conflict Resolution Procedure: `${CLAUDE_PLUGIN_ROOT}/skills/implement/references/conflict-resolution.md`. Invoke the Conflict Resolution Procedure with `caller_kind=early_rebase` and the parsed `CONFLICT_FILES` (spawn `larch:ci-fixer` `MODE=conflict`; do not Read conflicted hunks in the main agent). On success, continue. On hard failure, the procedure runs `"${CLAUDE_PLUGIN_ROOT}/scripts/larch.sh" git rebase-abort`, sets `STALL_TRACKING=true` (signals Step 19 cleanup's title-prefix terminal transition to rename the tracking issue to `[STALLED]`), and skips to Step 18.
   - **Exit 3 (`REBASE_OUTCOME=failed`)**: read `REBASE_ERROR=...` from the same stdout capture. If the value begins with `unexpected-rc-` (FINDING_9 prefix: non-1/3 non-zero exits rewritten by the wrapper), print `**⚠ Rebase onto main failed unexpectedly (exit $rc). Bailing to cleanup.**` (derive the numeric exit token from the suffix after `unexpected-rc-` when present; otherwise use the process exit code), set `STALL_TRACKING=true`, and skip to Step 18. **Otherwise** (non-conflict rebase failure: fetch error, detached HEAD, etc.): print `**⚠ Rebase onto main failed (non-conflict): $REBASE_ERROR. Bailing to cleanup.**`, set `STALL_TRACKING=true`, and skip to Step 18.
   - **Other non-zero exit**: the wrapper emits `REBASE_OUTCOME=failed` + `REBASE_ERROR=unexpected-rc-<n>` then re-exits with the original code: print `**⚠ Rebase onto main failed unexpectedly (exit $rc). Bailing to cleanup.**`, set `STALL_TRACKING=true`, and skip to Step 18 (same bail copy as the `unexpected-rc-` branch: parse the suffix after `unexpected-rc-` from `REBASE_ERROR` when present).
   - **Exit 0 (`REBASE_OUTCOME=ok` or `skipped`)**: this is defensive after a fail-closed macro load. On the captured stdout, check `SKIPPED_ALREADY_PUSHED=true` **before** `SKIPPED_ALREADY_FRESH=true` (wrapper preserves `scripts/larch.sh push rebase` precedence). If either skip marker is present, silently continue; otherwise continue. Phantom tail KVs (`PHANTOM_*`) may trail on the same stream: treat them as advisory per the **Phantom Untracked Probe** pointer (`PHANTOM_APPEND_WARN_ERROR` is already surfaced by the wrapper when warn-append fails).

**STALL_TRACKING**: the wrapper does **not** set `STALL_TRACKING`; the orchestrator sets it only on the bail branches above.
